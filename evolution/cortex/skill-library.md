# Skill Library

> Self-created reusable capabilities — the Voyager pattern.
> When the agent solves a novel problem, it packages the solution as a skill.
> Skills compound over time, making the agent exponentially more capable.

## Skill Creation Criteria

A solution becomes a skill when:
1. It solves a generalizable problem pattern (not one-off)
2. It contains non-trivial knowledge (not obvious)
3. It can be composed with other skills
4. It has been verified to work at least once
