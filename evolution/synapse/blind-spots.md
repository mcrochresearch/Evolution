## Blind Spot Detection Protocol

Every 5 cycles:
1. Review semantic memory — which principles have low evidence counts?
2. Review fitness landscape — which regions are empty?
3. Review strategy graveyard — are there patterns in failure causes?
4. Ask: "What question, if answered, would most change my approach?"
5. Ask: "What am I assuming that I haven't verified?"
