# Reflections

> Post-action self-reflection — the engine of conscious learning.
> Inspired by Reflexion (Shinn et al., 2023) — verbal reinforcement learning
> where the agent's own analysis serves as the reward signal.

## Reflection Protocol

After EVERY cycle, write a reflection answering these questions:
1. **What happened?** — Factual account (no interpretation)
2. **Why?** — Causal analysis (not just correlation)
3. **What did I learn?** — New knowledge or confirmed/refuted beliefs
4. **What should change?** — Concrete actions for next cycles
5. **Confidence** — How sure am I about this analysis?

### Quality Criteria for Reflections
- Be SPECIFIC — "the regex failed on edge case X" not "something went wrong"
- Be CAUSAL — "because the function doesn't handle null" not "it just didn't work"
- Be ACTIONABLE — "add null check to line 45" not "be more careful"
- Be HONEST — low confidence is valuable; false confidence is dangerous
