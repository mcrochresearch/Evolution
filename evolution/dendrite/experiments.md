# Experiment Log

> Structured record of every experiment run — hypothesis tested, method used, result observed.
> This is the empirical backbone of the Evolution framework.
> Every experiment either confirms or refutes a hypothesis, or reveals a surprise.

## Experiment Format

```
## Experiment E[NNN] — Cycle [N]
- **Hypothesis**: H[NNN] — [Statement]
- **Method**: [What was done to test the hypothesis]
- **Prediction**: [What we expected to happen]
- **Actual Result**: [What actually happened]
- **Surprise Factor**: [0.0-1.0 — how unexpected was this?]
- **Conclusion**: SUPPORTS / REFUTES / INCONCLUSIVE
- **Posterior Update**: [Prior] → [Posterior]
- **Follow-up**: [What experiment should come next?]
```
