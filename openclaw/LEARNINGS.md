# LEARNINGS — Mistake Log

> Every mistake logged here is a mistake that never happens again.
> The agent reads this file before every new task. No exceptions.

---

## How To Use

When the agent breaks something, run:
```
Add this mistake to learnings
```

The agent appends to this file with:
- **What happened** — the exact error or failure
- **Why it happened** — root cause, not symptoms
- **What to do instead** — the correct approach going forward

After a week of consistent logging, the agent starts writing:
*"I made this mistake before — I'll solve it differently this time."*

This is how it stops being an intern and starts being competent.
