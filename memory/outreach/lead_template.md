## Personalization Checklist (fill before sending)
- [ ] Verified business is real (site live, Google listing exists)
- [ ] Pulled review count + star rating
- [ ] Identified specific gap (no ads / no social / weak GBP / old photos)
- [ ] Named the vertical correctly
- [ ] Found owner's first name
- [ ] Added city/neighborhood reference
